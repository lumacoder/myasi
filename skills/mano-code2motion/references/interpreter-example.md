# 一次完整解释，不做关键词替换

输入：“把球移动到右边，要丝滑，有厚重感，动作利落；不要花哨特效。”

## 先解释歧义
- “丝滑”可能指球本身起停连续，也可能指相机平稳。此处没有相机描述，假设固定镜头、球的根平移连续。
- “厚重”可能指慢起动，也可能指落地冲击。此处是水平移动，选慢起动/晚峰速/稳固停住，不编造落地或弹跳。
- “利落”可能指短总时长，也可能指收尾干净。与厚重的慢起动冲突，优先保留主体重量，选“无回弹、到达后稳定”；若用户指快速响应，应另给更短版而非自称同时完美满足。
- “不花哨”是硬约束：无粒子、闪白、震屏、运动模糊。造型参考另定，球的平移动画不能证明人物绘制能力提升。

## 到参数
| 观察目标 | 编译选择 | 反例 / 检查 |
|---|---|---|
| 连续起停 | 开始/到达速度0；候选smootherstep用于丝滑对照 | 线性接静止只有位置连续，不能用fps遮掩 |
| 迟缓起动、晚峰速 | 厚重候选时间贝塞尔(0.7,0,0.8,1) | 不是空间控制点；必须求Bx逆。峰速时间应晚于对称曲线 |
| 收尾干净 | to后保持，rebound=0（不新增轨道） | 结束后反复弹回不合格 |
| 对照公平 | 同造型、870px、0.5s起动、2.6s运动 | 不用不同物体/光效冒充运动提升 |

可执行数据在 `../examples/compare.json`，其中 `heavy` 是上述解释的候选结果；`smooth` 与 `linear` 是拆开语义的对照，不是把三条运动叠加。

运行检查后可以获得：线性速度约334.6px/s；丝滑候选峰速约627.4px/s，峰值在约1.80s；厚重候选峰速约705.7px/s，峰值在约2.57s。后三位取决于有限差分采样；这些只是当前规格的测量，不是“厚重”的客观标准。

## 如何否决本轮
如果正常回放看起来像“先犹豫再冲刺”，即使所有数值通过也不接受。下一轮应降低峰速对比、调整时长或明确推力，而不是添加尘土掩盖。若用户更重视利落，缩短起动并保留零回弹，记录重量感有所牺牲。

`semantic-plan` 记录动因/材质/叙事/取舍；`MotionSpec` 只记录执行器能实现的值；渲染证据检验假设。三者都需要，不把未实现的故事说明算作视频已经具备的能力。
