# 语言生成代码的精华（ distilled ，不是原文引用）

来源：Florence @flxrnc 的 Opus 5.5 Motion Lab（2026-09-30）、Fable 5.2 Motion Playbook（2026-11-10），以及她 2026-11-19 的 18 个仓库清单（见 `sources.md`）。以下只保留可执行的规则与数字，不复制原文提示词与代码。

## 第一性原理
模型只输出文字，从不直接碰像素。所有“视频”都是一段程序：给时间 t，画出那一帧；浏览器逐帧截图，ffmpeg 拼成 MP4。
- 同一输入必须给出同一帧，否则无法修。
- 改动就是改一个数字再重渲，不是重新抽卡。
- 模型能看自己的帧：先渲静帧、读图、改，再渲全片。

## 渲染契约（每段作品都必须满足）
- 一个自包含 HTML 文件；只用点名的库，版本钉死。
- 除字体与点名库外无网络请求。
- 每帧是 t 的纯函数：`window.renderAt(t)`，无 `Date.now`、无定时器、无 CSS 过渡、无 `requestAnimationFrame`（渲染模式）。
- 只用有种子的噪声，不用 `Math.random`；帧与帧之间不带状态。
- 等 `document.fonts.ready` 再渲第 0 帧。
- 循环只渲 0 到 N-1 帧；第 N-1 帧必须能接回第 0 帧。
- 帧用 PNG 进编码器，不用 JPEG。

## 形容词换数字
| 你想说的 | 改成这样写 |
|---|---|
| 高级感 | 材质：粗糙度 0.38、清漆 0.35；入场 ease-out-quint，文字无回弹 |
| 冷光 | 主光 3200K、轮廓光 7500K，各写强度 |
| 现代镜头 | fov 30，不停机，一次 ease-out-expo 推近，写在 2.0s |
| 干脆 | 时长写帧数，弹簧写阻尼比 |
| 抓眼 | 缩放 1.0 → 1.08 → 1.0，共 6 帧，峰值落在节拍上 |
| 拖沓 | 每个停留砍掉一个节拍 |
| 太满 | 一次只一个主动作，其他动作晚 150ms、行程 60% |

## 提示词模板（每行都要填，空着不写）
```
GOAL： 一句话，观众看完感受到什么 / 会做什么。
OUTPUT： 引擎 + 尺寸，如一个 three.js 场景、一个 HTML 文件、1920x1080。
TIME： 秒数 x fps = 帧数；是否循环。
LOOK： 十六进制调色板、一个强调色、字体/字重/字号/字距。
MOTION： 入场/移动/退场的缓动曲线、弹簧阻尼比、时长（帧）。
SHOTS： 帧区间、每镜头一个主动作、交接方式（切/匹配切/遮罩擦除，默认切）。
MODEL/CAMERA（3D 才写）： 对象是什么、fov、唯一一次相机移动。
IDENTITY LOCK： 绝不能变的东西（logo 比例、角色形状）。
ASSETS： 真实 logo、真实界面、真实数字；缺了停下来问，不画假的。
BANNED： 见下。
QA： 先看哪些帧的静帧与联络表，得到我确认后再全渲。
```
先写 GOAL，再写 TIME；写不出 GOAL 的一句话，缓动救不了。

## 数字速查
- 缓动：入场 ease-out-expo `0.16,1,0.3,1`；高级入场 ease-out-quint `0.22,1,0.36,1`；移动 ease-in-out-quart `0.76,0,0.24,1`；退场 ease-in-expo `0.7,0,0.84,0`；俏皮回弹 ease-out-back `0.34,1.56,0.64,1`。入场用 ease-out，退场用 ease-in，退场比入场短 40–50%。
- 弹簧：阻尼比 1.0 不弹、0.7–0.85 显高级、0.4–0.6 活泼、<0.3 卡通。位置与尺寸可弹，不透明度与颜色不弹。弹簧必须写成时间的闭式函数，不要逐帧积分。
- 时长：UI 反馈 100–200ms；UI 移动 200–500ms；主角揭示 600–900ms；字母间隔 1 帧；词间隔 60–120ms；列表项 40–80ms；下一个动作在上一个完成 30–50% 时开始。
- 层级：每镜头一个主动作；次动作行程为主动作的 50–70%，晚 100–200ms；环境动幅度 < 主动作行程的 5%。每 2–4s 有新东西；钩子在前 2s 落地。
- 停留：屏幕文字至少 0.3s/词 + 0.5s；两词标题至少 1.1s；停留时保持约 2% 的缓慢推近，画面不死。
- 节拍：每拍帧数 = fps × 60 / BPM；每拍单独取整，不累加取整值。切在节拍上，布局在小节（每 4 拍）换。
- 挤压拉伸：下蹲 1.2×0.75、起跳 0.85×1.28、落地 1.25×0.75，保持体积；跟随：手臂滞后 4 帧，尾巴/领带滞后 6 帧。
- 清晰度：文字与 UI 单独一层，在景深/模糊之后画；最近镜头处至少 1 texel/输出像素（近景 2x， 特写 3x）；颗粒 ≤0.02；PNG 帧，终编 crf ≤18；交付前看全尺寸最近镜头与尾卡，文字放大 200% 检查。
- 无障碍：文字对比度每帧 ≥4.5:1；闪烁 ≤3 次/秒；手机上关键姿势比感觉上再推大 10–30%。

## 禁单：把默认逐个点名
居中标题加渐变、全部同时淡入、每个元素都淡入上滑、处处居中、紫蓝渐变、光晕（含 UI）、光斑、辉光、霓虹、镜头光晕、装饰粒子、粒子爆开、角落标签、画框边、通用旋转展台、文字在阅读时还在动、死时间。
每轮把实际出现的默认追加进去；只写“避免 AI 味”没用。

## 时间总谱先行，写清“完成”
- 先写 timing 文件：节拍、每拍帧号、每个事件帧号、声音落点；它是主时钟。
- 再写“完成”的定义：MP4 渲出、每项 QA 有数字、未测项列出；长任务容易提前收尾，写清定义能少一半烂尾。
- 预算纪律：静帧与小改用低成本模式，全片构建再用高成本模式；静帧上修一轮，再全渲。改动中途提交，风格在全量构建前锁定。

## 运动量测（静帧会撒谎）
- freeze 检测：≥0.5s 无变化即告警；有意静止要写明意图，不加假动作刷指标。
- 运动曲线：画每秒变化量，看动作是否真的在动、峰值是否落在事件帧。
- 主体测量：每主镜头量主体像素宽；1080p 下至少 170px。
- 帧号核对：关键动作晚 1 帧就是错，写帧号，不写感受。
- **自己按正常速度看一遍**，听一遍声音；只看静帧不能判运动，只看表不能判声音。

## 声音与字幕（只列本技能已有的做法）
- 画面先静音成立；声音落点比画面晚 1 帧；撞击声比音乐床高 3–6dB；母带 -14 LUFS，真峰 ≤-2 dBTP（AAC 编码后复测）。
- 声音来源顺序：Openverse（只用 CC0/公有领域/CC BY）、真实录音、代码合成；每 10s 约 5 个设计音效，少即是多。
- 字幕用 WhisperX 类工具按词时对齐（毫秒级），或按 `production.md` 的帧级字幕表手工对齐；≤2 行，放在留白处。

## 按镜头选路（不为一次画面造通用引擎）
| 要做的片子 | 首选路 |
|---|---|
| 10s 内、产品片、UI 动效、字体、数据、发布讲解 | HTML + 逐帧渲染 + ffmpeg，或 HyperFrames |
| 模板化系列、数据驱动、React 团队 | Remotion（有官方 agent skill） |
| 浏览器 3D、抽象或产品镜头 | three.js |
| 写实 3D、真实光、物理、绑定角色 | Blender（脚本驱动，无界面渲染） |
| 数学、公式、图解 | Manim |
| 矢量讲解、配音同步 | Motion Canvas / Revideo |
| 应用内动效：图标、加载 | Lottie / dotLottie |
| 交互、状态驱动的应用动效 | Rive |
| 网站内的实时动效 | Motion / GSAP |
| 人、写实场景、有机运动 | 视频模型（Veo/Kling/Seedance/Runway 等），注意不能 seek、不能精确卡节拍、文字常出错 |

## 18 个仓库的取舍（2026-11-20 核对，见 `sources.md`）
只学机制与契约，不复制代码、提示词长文、媒体、字体或模型：
- 复刻：reanimate（逐帧反推）、motion2code（参考动作重建为 SVG + GSAP）。
-  timing/缓动：motion-design-skill、mg-styles-15（15 种风格，各一 prompt）。
- 风格：huashu-art-motion（35 种艺术风格）、anidoodle（涂鸦与循环，纯代码）。
- 影片：cinetic（代码出发布片）、motionmaxxing（把 AI 味片子改成设计师级）。
- 引擎：Manim、blender-skills、three.quarks（粒子）、react-postprocessing（电影感收尾）、EffectCraft（Rust 合成）。
- 调参与声音：Tweakpane（滑杆调参）、librosa（找节拍）、Openverse（免费声音）、WhisperX（逐词字幕）。
- 交付：Remotion Skills、FFmpeg。
- 本技能不导入以上任何仓库的代码与素材；需要时在项目里按各自许可单独引入，并记录来源。
