# 工程契约：把感觉变成可讨论的量

## 两种贝塞尔不能混用
**空间**三次贝塞尔 B(u)=(1-u)^3 P0+3(1-u)^2u P1+3(1-u)u² P2+u³ P3，输出 px 坐标。u 均匀递增通常不等速；要匀速沿曲线，建立弧长表，再把累计距离映射回 u。

**时间** CSS cubic-bezier(x1,y1,x2,y2)：输入归一化时间 q=(t-start)/duration，先求 Bx(u)=q，再取 By(u)。不能直接把 q 代入 By！x 控制点必须在 [0,1] 才能单调求逆；本执行器允许 y 越界（预备/回弹），但 opacity/scale 等属性还受语义范围约束。脚本以二分求逆，含端点精确处理；它不是空间路径。

标量值 p=p0+(p1-p0)E(q)。速度 v=(p1-p0)/duration * E'(q)，单位 px/s、rad/s、scale/s；加速度相应除 duration²。三维情况逐分量计算。不同位移/时长的接段，即使控制点相同，也未必速度相同。

## 连续性：位置不是速度
- C0：接段位置相等。线性移动接静止通常只有 C0（速度跳变）。
- C1：一阶导数也匹配，矢量方向和量值都匹配，不只比较速率。
- C2：二阶导数也匹配。
- smoothstep=3q²−2q³ 端点速度为0，接静止是 C1，但端点加速度非0，**不能说它一定 C2**。
- smootherstep=6q⁵−15q⁴+10q³ 端点速度/加速度均为0，接静止可 C2。它仍不能自动解决中途接段、锁脚、遮挡或语义问题。
- 弹簧位置连续不代表初速度连续；使用解析阻尼模型时保留上一段速度并明确质量、刚度、阻尼和单位，不做每帧随机抖动。

附带 check 报告用有限差分采样并注明步长；它不是解析连续性证明。瞬间切镜允许画面不连续，但应标为剪辑意图，不能当插值接段混过去。

## v1 数据与能力
schema 是 JSON Schema 2020-12；`scripts/motion.py` 内置验证器只实现该文件实际使用的子集（本地 $ref、type、required、additionalProperties、properties、items、长度/数值界、enum、pattern），不是通用 JSON Schema 引擎。

- `canvas` 是输出像素；`fps` 是采样率；`duration_s` 精确要求整数帧数，以免末帧/视频时长含糊。视频采样 i=0…N−1，时间 i/fps；交互 seek 可以看到 duration_s 的最终保持态，但不额外编码一帧。
- 坐标原点左上，x向右、y向下，距离 px；rotation_rad 顺时针弧度；scale/opacity 无量纲；时间全用秒。没有隐式 ms。
- `objects` 为有固定造型的圆或矩形；tracks 为单对象单属性区间，每段 from/to/ease；支持 x_px、y_px、scale、rotation_rad、opacity；不支持空间曲线字段、3D、摄像机、粒子或骨骼。字段越界/未知会被拒绝。
- 同对象同属性不得重叠，首段 from 必须等于对象初值，后段 from 必须等于前段 to；段间保持，接段仅保证 C0，不保证 C1/C2。有意跳切应切成新镜头资产，而非偷偷塞进数值轨道。
- 曲线对于 opacity/scale 的越界采用保守限制：仅接受不越界的控制点 y；位置可预备/回弹。需要复杂裁切或负缩放请显式扩展版本。
- `intent` 是人读的解释和验收依据；执行器不从原词推导轨道，不把未实现的语义当成已实现。
- 所有帧每次清屏并从 t 求值；seed 以无状态 hash(seed,index) 提供固定噪声。扩展粒子需每粒子固定出生时间/索引，不依赖上帧。

## 渲染器替换边界
Canvas2D 适合本例和矢量/分层动画；角色复杂绘制应先有关键原画/造型与绑定，不靠堆手估坐标。3D 用 Blender/Three 等适配器；排版视频可用离线合成器。选择依据是画面与可验证性，不是库数量。适配器必须读同样单位契约、支持 seek 和固定 seed、拒绝不支持字段、记录版本/字体/外部资产，补数值与像素测试。真实跨机器逐像素一致需固定浏览器、OS、字体及编码器版本，本技能不承诺跨平台哈希一致。
