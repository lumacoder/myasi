# 造型、叙事与跨镜头连续性：学习机制，不收集风格名

按需使用 `templates/style-bible.md`。一个风格应有“形状语法+线/材质+运动习惯+构图/字”的可执行规则和失败图，不是给普通圆矩形叠滤镜。先在自己的题材上试宽景/特写/复杂动作2–3帧，观察与预期的差距，才推广。

## 把来源中有用的方法变成可选择的制作决定
| 观众任务 | 可编写的机制 | 不该拿什么冒充 |
|---|---|---|
| 读出纸的重量 | 多边形边缘、局部固定纤维、折面分组旋转、接触阴影随距离收紧；纹理随纸移动 | 全屏噪点、所有物体同一个软弹簧 |
| 读出印刷/线稿 | 网点/排线跟随体块方向与密度，主轮廓独立；有限色套印偏移只在允许区域 | 随机抖线掩盖造型错；手机缩小后材质消失 |
| 一眼懂科学因果 | 一种概念占用一个颜色；路径/箭头/连接按因果时序增长；标签后到、先退 | “分子”标签给不守拓扑的球串；显微风的发光被当真实实验 |
| 产品部件的层次 | 父级局部坐标、明确爆炸轴/顺序、遮挡预算、引线锚定部件、装配状态保留 | 全部零件同向匀速浮走、玻璃/金属只换颜色 |
| 角色在空间中表演 | 接触锚点、姿势适配、视向与卡片朝向、相机不越轴、前景遮挡检查 | 纸片角色在3D里无端翻背；脚滑或标签代替情绪 |
| 字型/界面动作 | 强调词与真实cue对齐；局部timeline可绝对seek、无状态随机；组件卸载清理 | 120招全部铺满；每个词都跳；只优化transform就宣称表演好 |
| 同一主体经历变化 | 固定身份色/轮廓/道具；镜头前后对表；回到早先构图时体现变化 | 每镜头重新随机造人、不同材质被称“同一风格” |
| 风格参考→原创表达 | 量主体占比/留白/线宽/调色用途/相机/帧保持，重画自己的对象与动作 | 复制参考角色、视频、字体或示例代码却只写“灵感” |

`runtime/scene-kit.js`是可忽略的小工具：索引采样、有限帧保持、**按弧长**截取描线、可替换backdrop/post/draw钩子；不能表达的东西直接写自己的函数。它不定义通用角色，不是完整风格引擎或3D渲染器。

## 叙事语法服务于需求，别反过来
- 过程：前一步真的制造下一步；因果能从无字幕画面读出。短机制演示可以只有一次事件，不必扩成长故事。
- 年代/阶段演进：保留身份线索，用有依据的形状接续/尺度变化连接；事实与“第一”另有来源台账。
- 任务/旅程：观众抓住主体，必要时主体固定而世界换；紧段节拍可以收密，连接/结果应该有可读停顿。
- 列表/产品：有信息层级，不强塞主角冒险。循环片才检查首尾无缝；叙事结尾可以“回到原景但改变了”。
- 每个切换写一句用途：因果、视点、尺度揭示、时间省略、形状/位置接续、callback。**不强制所有片都beat-cut、相机一直动或每3秒必须有动静。**

## 自测反例
1. beat-grid全对但句意没结束就切走 → 先修改时长与信息分组，不是增加转场。
2. 字符包围盒没超界但被手/手机UI挡住 → 查实际像素；几何/DOM测量不等于OCR或可读性。
3. 媒体“已verified”但只证明文件存在 → 在自己的题材与交付尺寸重新看，来源的速度/评分不继承。
4. 音频峰值对齐接触帧，但音色像电子提示而非木头 → 数字同步通过、表现力仍可partial/fail。
5. 最后1秒有意静止，被freeze扫描标出 → 保留意图并人工核对，不添加假动作刷指标。
