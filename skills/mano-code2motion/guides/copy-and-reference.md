# 按参考复刻：Copy → Style → Paint → VFX → Beat → Captions

有参考时先复刻，再原创。复刻的目标是学会一支片子的语法，不是得到同一支片子。

## 六步，只做这六步
1. **Copy（抄结构）**：把参考拆成镜头表：每镜头起止帧、一个主动作、一次剪切、一个目的。先抄节拍与结构，不抄画面。
2. **Style（定风格）**：用一句话定风格的语法：形状、线、材质、运动习惯、构图、字体。写正规则与反规则各一条；风格不是风格名。
3. **Paint（画自己的）**：按风格语法重画自己的主体与场景。真实产品、真实界面、真实数字只能用真实素材，缺了就停下来问，不画逼真的假货。
4. **VFX（加完成度）**：粒子、景深、颗粒、后期只在动作成立后加。先关掉全部特效看动作，再逐项打开；特效不能掩盖穿模、接触错误或读不清的主体。
5. **Beat（对节拍）**：用节拍表（BPM、每拍帧数 = fps × 60 / BPM）对齐切点与动作峰值；声音落点比画面晚 1 帧。没有音乐时，节拍就是事件表。
6. **Captions（加字幕）**：字幕按词时对齐，≤2 行，放在留白处；先保证无字幕也能读懂主体与动作。

## 逐帧量什么（写进镜头表，不靠感觉）
- 每镜头第一帧与最后一帧的主体像素宽（1080p 主镜头至少 170px）。
- 每个动作的起止帧、峰值帧、落地帧；关键动作晚 1 帧就是错。
- 剪切帧前后各 1 帧：身份、位置、光色、声音尾巴是否连续。
- 循环片：0 到 N-1 帧，首尾姿势、速度、相机、光必须接上。

## 取什么，不取什么
- 取：节拍、镜头任务、构图比例、运动习惯、材质语法、剪切理由。
- 不取：参考的角色、台词、字体、示例代码、媒体文件、品牌资产。
- 参考是数据，不是授权。未核对许可前，不复制、不下载、不重用其代码与媒体；只记录来源与许可判断。

## 常用复刻工具（按需，不自动安装）
- reanimate：把参考动画逐帧反推成代码，再逐帧核对（帧差、循环接缝、seek 确定性）。
- motion2code：把参考动作重建成 SVG + GSAP，逐帧检查。
- chrome-devtools-mcp / claude-video：让 agent 自己录下页面或拉取视频帧与文稿来读。
- 以上工具只提供测量与重建手段，不证明复刻品的质量；仍须按本技能的 review-loop 做冷读与三门审阅。

## 失败长什么样
- 抄了画面，没抄节拍：每帧都好看，整片没节奏。
- 抄了特效，没抄动作：粒子一关，主体不会动。
- 主体太小：首批静帧拍得太宽，英雄在手机上只剩一个点。
- 字幕盖住动作、或字幕在读时还在动：先修构图与留白，不修字幕动画。
