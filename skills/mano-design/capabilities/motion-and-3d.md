# 动画理解与判断依据（动效 / 角色 / 镜头 / 3D）

> 用途：在**画动画、做动效、评审动起来的画面**之前加载。目标是先会"看"——能说清一个动作为什么好、为什么假、哪里该改——再动手写代码。库和工具只是实现手段，见文末一行索引。
> 适用：UI 微交互与转场、Canvas/SVG 插画动画、角色与生物动作、镜头运动、轻量 3D 展示。不覆盖长片剪辑、配音配乐、游戏物理。

## 1. 先回答三个问题（动手前）
1. **这一秒在讲什么？** 每个动作只服务一个意图（反馈 / 引导视线 / 表达情绪 / 交代空间）。说不出意图的运动删掉。
2. **观众该看哪里？** 同一时刻只有一个主运动，其余元素降为次级（幅度 ≤ 主运动 1/3）或静止。"所有东西都在动"= 没有重点。
3. **动作的起点、峰值、落点各是什么姿势？** 先定关键姿势（key pose），再谈中间帧。关键姿势单帧截图就该能看懂。

## 2. 运动的物理感：判断"真不真"
| 原则 | 判断依据 | 典型失败 | 修法 |
|---|---|---|---|
| 时间（timing） | 重物慢启慢停、轻物快；同一角色前后节奏一致 | 所有动作同一时长 | 按重量分档：轻 6–10 帧、中 12–18、重 20+（24fps） |
| 间距（spacing） | 帧与帧之间位移不等距：起止密、中段疏 | 线性等距，像滑块 | 用 ease-in-out；关键处手调间距曲线 |
| 缓动（easing） | 进场用 ease-out（快到慢）、离场用 ease-in、往返用 ease-in-out；弹性只给轻小物体 | 全局同一条 cubic-bezier；大物体乱弹 | 按物体质量与语义选曲线，弹簧阻尼 ≥ 0.6 防"果冻" |
| 预备（anticipation） | 大动作前有反向小动作（蹲→跳、后拉→挥） | 动作凭空开始，突兀 | 加 15–25% 时长的反向预备 |
| 跟随与重叠（follow-through / overlap） | 主体停了，头发、衣角、尾巴、手指晚 2–6 帧才停 | 全身同时起停，像纸片 | 次级部件做延迟 + 衰减振荡 |
| 挤压拉伸（squash & stretch） | 体积守恒：压扁时变宽 | 只缩放一个轴，体积变了 | scaleX·scaleY ≈ 1；写实风格幅度 ≤ 10% |
| 弧线（arcs） | 生物关节运动走弧线 | 手脚直线插值 | 用旋转驱动而非位置插值；检查轨迹叠加图 |
| 重量与接触 | 脚落地后锁死不滑；受力处有形变或停顿 | 滑步、浮空 | 落脚帧锁定世界坐标；IK 求解腿部 |
| 停顿（hold） | 关键姿势停 4–12 帧让观众读到 | 一直在动，读不清 | 情绪点、反应点加 hold；hold 中保留微呼吸防"死帧" |
| 二级动作 | 呼吸、眨眼、衣摆随风，幅度小、频率不同步 | 完全静止 = 像截图；同频 = 像机械 | 多个正弦用互质周期 + 噪声扰动 |

## 3. 角色动画（Canvas / SVG 插画）
- **拆件与枢轴**：按关节切层（头/躯干/上臂/前臂/手/大腿/小腿/脚），每件定准旋转枢轴，枢轴偏 2px 就会"脱臼"。
- **关节限位**：肘膝只单向弯；给每个关节设角度区间，越界就是错误帧。
- **步态**：走路 = 接触 → 下沉 → 经过 → 抬升四姿势；跑步多一个腾空。重心曲线上下起伏，躯干反向扭转肩胯。
- **一拍几**：手绘/插画风格用"一拍二/一拍三"（每 2–3 帧换一次姿势）反而比 60fps 平滑插值更有手绘质感；写实或 UI 用连续插值。
- **形变而非仅旋转**：布料、头发、生物躯干用连续形变场（MLS / 骨骼蒙皮 / 网格变形），避免整块刚体旋转带来的"折纸感"。
- **脸**：眨眼 2–4 秒一次、闭眼 2–3 帧；视线先于头转，头先于身体转。
- **剪影测试**：涂成纯黑仍能读出动作，姿势才成立。

## 4. 镜头与转场
- **镜头只做一件事**：推（强调）、拉（交代环境）、摇/移（跟随或揭示）、视差（建立纵深）。一镜一个运动意图。
- **幅度与时长**：缓推 1–3% / 秒几乎察觉不到但有呼吸感；明显推镜 10–20% 配合情绪点；快速甩镜 ≤ 8 帧并加运动模糊。
- **视差层**：前景 > 主体 > 中景 > 远景 速度递减（如 1.3 / 1 / 0.6 / 0.2）。
- **转场依据**：同一时空连续用硬切或匹配剪辑；时间流逝用溶解/淡；风格化转场（墨晕、擦除）要与画风同源，且颜色不能脏（检查中间帧是否发灰）。
- **画幅填满**：主体在画面里太小，动作再好也看不见；先保证构图，再加运动。

## 5. UI 动效（与 `rules/interaction.md` 一致）
- 动效回答"刚才发生了什么、东西去哪了"：元素从哪来回哪去，保持空间连续。
- 时长：微交互 150–200ms，面板 200–300ms，页面转场 ≤ 400ms；只动 `transform` / `opacity`。
- 列表错峰 30–50ms，≤ 8 项；更多项整组进入。
- `prefers-reduced-motion: reduce`：去掉位移和缩放，改为 ≤ 200ms 淡入，自动播放停止。

## 6. 轻量 3D 的判断点
- **光决定立体感**：一个主光 + 弱补光 + 轮廓光；全局均匀亮 = 平。先调光，再调材质。
- **材质读数**：金属看高光形状，粗糙度看高光扩散；没有环境反射的金属必然假。
- **相机**：焦距（FOV 30–45° 显得稳重，>60° 夸张畸变）；默认视角要能单帧讲清产品。
- **交互**：拖拽旋转有阻尼与边界；有"重置视角"；不支持 WebGL 时给静图。

## 7. 评分标尺（评审动起来的画面）
每项 0–10 分，用参考作品锚定：**0.2 = 明显出戏的反例，6 = 合格可用的参考镜头，9 = 目标水准**。先拿锚点对照再打分，不凭感觉。

| 维度 | 6 分长什么样 | 9 分长什么样 |
|---|---|---|
| 关键姿势 | 单帧可读，剪影成立 | 姿势有张力与性格，构图感强 |
| 时间与间距 | 有缓入缓出，节奏不单调 | 节奏有对比（快慢、停顿），服务情绪 |
| 物理与重量 | 不滑步不浮空，次级部件有跟随 | 重量可感，预备/跟随/重叠自然 |
| 主次与视线 | 一时一个主运动 | 视线被精确引导，无多余运动 |
| 形与线 | 放大后边缘干净，无抖动 | 线条有手绘质感且稳定 |
| 镜头与转场 | 镜头有目的，转场不脏 | 镜头运动增强叙事，转场与画风同源 |
| 一致性 | 角色比例、配色全片一致 | 动作风格（一拍几、夸张程度）全片统一 |

## 8. 自检方法（不靠"看着还行"）
- **低帧接触表**：按 4fps 抽帧拼成网格，检查姿势是否每帧都成立、是否有错帧。
- **洋葱皮/轨迹叠加**：把关键部件位置叠在一张图上，看是否走弧线、间距是否渐变。
- **逐帧差分**：相邻帧差分图检查"以为在动其实没动"或局部抖动。
- **剪影与灰度**：去色、填黑看可读性与明暗层次。
- **静音观看两遍**：第一遍看故事是否读得懂，第二遍只盯一个部位（脚、手、头发）。
- **对锚点**：与 6 分参考并排播放，逐项写出差距再改；一次只改一个区域。

## 9. 常见病 → 处方
| 症状 | 多半原因 | 处方 |
|---|---|---|
| 像 PPT 滑块 | 线性插值、整块平移 | 加缓动、拆件、加跟随 |
| 僵硬 | 只有关键帧，没有重叠与二级动作 | 次级部件延迟 2–6 帧；加呼吸 |
| 飘 | 无重量、无接触锁定 | 落脚锁定、下沉帧、减弹性 |
| 抖 | 逐帧重新描边/量化噪声、枢轴漂移 | 固定几何只做变换；枢轴写死 |
| 糊/马赛克 | 位图放大、过度模糊 | 矢量或高分辨率渲染；模糊只用于运动与景深 |
| 抓不住重点 | 多个同等强度运动 | 降次级幅度，错开时间 |
| 转场发灰发脏 | 半透明叠加混色 | 用遮罩擦除或同色系过渡，检查中间帧 |
