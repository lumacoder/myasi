# 中文文案：去 AI 味
- 写「动作 + 对象 + 结果」：「导出本月账单（PDF）」，不写「一键开启高效之旅」。
- 套话词表（`cp.ai-cliche`，命中 ≥2 处为 major）：赋能、一站式、全方位、极致体验、无缝、革命性、颠覆、释放潜力、开启全新…之旅、打造生态、全链路、引领未来、重新定义、下一代、前所未有、触手可及、尽在掌握、助力；英文 unlock / elevate / seamless / empower / supercharge / cutting-edge / unleash / next-generation / to the next level。
- 按钮用动词，写明后果：「删除 3 个文件」「保留」，不写「确定/是」（`cs.dialog-vague-buttons`）。
- 链接说明去向：「下载发票 PDF」，不写「点击这里」（`cp.vague-link`）。
- 错误 = 原因 + 办法 + 入口：「网络已断开，草稿已保存。重新连接」，不写「出错了」（`cp.vague-error`）。
- 空状态 = 现状 + 下一步：「还没有项目。新建项目」。
- 标题和按钮不放 emoji（`cp.emoji-heading`）；标点全角，中英文/数字之间加空格；统一用「你」或「您」。
- 不编造数据、客户 logo、评价；没有真实内容时用明确的占位标记。
