# 配色和谐（可计算的检查）
- **对比度**（WCAG 1.4.3 / 1.4.11）：正文 ≥4.5:1；大字（≥24px，或 ≥18.66px 粗体）≥3:1；图标、输入框边框、焦点环 ≥3:1。`ui_lint` 计算内联与样式表颜色（支持 var() 解析、半透明混合）；复杂页面用 `browser_check.py` 读计算样式。
- **色相数量**：有彩色（饱和度 >0.25）按 30° 分桶 ≤4 桶：1 主色 + 成功/警告/错误。超过记 `co.palette-sprawl`。
- **色阶**：主色用 Leonardo 或 OKLCH 生成 50—900；文字/背景从中性色阶取值，不手调灰度。
- **饱和度**：大面积背景饱和度 ≤0.2（HSL）；高饱和只用于小面积强调。
- **渐变**：默认不用；需要时同色相明度渐变。紫色跨色相渐变记 `co.ai-gradient`。
- **暗色模式**：背景 #0B0B0F—#18181B，正文 #E4E4E7 左右，次要文字仍需 ≥4.5:1；主色提高明度、降低饱和；不用纯 #000/#FFF（`co.dark-mode-pure`）。
- **状态不只靠颜色**：红绿状态同时有图标或文字（`co.color-only-status`）。
