# mano-3dmodel-gen 0.3.0

充当自然语言与大模型之间的 3D 模型工作流：把用户一句话扩成场景简报、场景规格、逐机细节提示词，按玩具比例系统建成 Web 3D 场景与动画。视觉与技术完全取自 Nyxera0x/simulator（MIT），只提炼逻辑，不锁定任何具体物品。

来源：github.com/Nyxera0x/simulator（MIT）。本 skill 只留可执行的规则与数字，不全文引用原仓库代码；原仓库四个场景的机器清单只作角色映射的示范，不当模板抄。主入口见 [SKILL.md](SKILL.md)。

## 0.3 新增

- **先 1:1 抄源码再建审核**：有原片时，场景模块哈希与源仓库逐文件一致，NEVER 未抄源码先重推导；重推导、凭感觉改参数即 P0。
- **逐帧对比**：t=0/5/10/16/20/30/40，同一视口/DPR，capture 模式暂停循环后截图；先遮掉选中标记与 UI 区域再算像素差，差 >0.1% 即 P0，须定位差异区域。
- **代码值核对**：阴影贴图/半径、灯光/曝光/雾、相机、筒轮廓与溜槽、浇筑流、围栏/基坑/土堆尺寸，逐项对源码值（含 file:line）；抄覆盖值，不抄底座值。
- **四类缺陷检查**：低级错误（NaN 扫描 0）；阴影（贴图尺寸与半径逐项比）；穿模（OBB 每 0.1s 扫查，盒在干净状态下算，允许清单只放源码确认的接触）；模型/动画（水泥车几何、浇筑流路径/时序/湿区逐项比，t=27.4/30/33.6 三帧实测）。
- **门禁**：审核脚本输出 JSON 报告 + 一页摘要，存项目目录；任一 P0 即 FAIL，不交付；审核脚本自身报错先溯源脚本期望值。
- SKILL.md 71 → 75 行；§1 加载纪律加半行：有原片时先 1:1 抄源码。沉淀自施工工地 1:1 重建（审核 143 项全过，P0 125/125；逐帧差异 <0.001；OBB 0 命中；NaN 0）。未验证：真机 GPU 流畅度；平台 audit 超时（沙箱限制）。

## 0.2 新增

- **先定交付性质**：模型展示页 = 全屏 canvas 一个，零 DOM 覆盖层；UI 面板与选中/高亮覆盖层只在产品页/控制台类交付物里出现；每轮修完即发布，发布后核对线上与本地 bundle md5 一致。
- **布局基准框**：以地块矩形为唯一基准框统一推导围栏/道路/大门/搅拌站/Plot，禁止逐段手算；布局数字先读源码写进规格表。
- **机器与路径**：先定前向轴再摆工作件；载荷按源码形态与缩放公式建；圆柱/条先旋长轴再缩放；路径逐点校验（禁尖点、切线平行于路、只画源码定义的路线、路线带逐点贴地）。
- **浇筑与探针**：抛物线照源码原公式；浇筑靠湿区圆盘 + 溜槽口灰色表达；选中框每帧现算世界 AABB、初始隐藏、t=0 单独验收；定帧截图前先暂停循环；“像穿模/错位”先查源码再定性；相机参数照源码抄。
- SKILL.md 67 → 71 行；五规则第 4/5 条改为仅产品页适用。沉淀自施工工地第一次试跑（7 轮）。

## 0.1 新增

- **6 行场景简报**：场景 / 主体 / 动作 / 情绪 / 时长 / 出口，写代码前先把意图钉死；另附场景提示词与细节提示词两段模板。
- **五规则 + 视觉系统**：一个相机、玩具比例、两色、真软件在上、游戏式选中；地面 #d5def7、车身蓝 #3166ea、作业件黄 #f2b33a；Neutral 曝光 0.93；相机 fov 28°、方位 38°、俯仰 36°；圆角盒倒角 12%、clearcoat 0.35。
- **角色映射的模型词汇**：搬运 / 举升 / 浇注 / 平整 / 堆叠，先定角色再选机型，NEVER 先抄机型清单。
- **render(t) 时间轴**：纯函数时间轴，一条主角旅程 + 3–5 个事件；总长 38–52s。
- **Web 3D 交付**：renderAt(t) 契约、esbuild IIFE 单文件、live 站点就是交付物。
- **原项目检查法**：首帧定生死、逐帧对照、碰撞扫查（每 0.1s）。
- **两个压缩案例**：施工工地（Buildline 主线）、飞机物流卸货园区（Rampline + Stockline 主线）。

## 与其他 skill 的关系

- mano-design 管静态视觉，mano-motion 管动效，mano-code2motion 管代码成片的工作流。
- mano-3dmodel-gen 管自然语言到 3D 模型：提示词扩写、场景规格、模型词汇、时间轴。要一个 3D 场景时先用本 skill 定场景与模型，再按 mano-code2motion 的交付契约出片。
- town-model-gen（同仓库）输出可导入 AITown 的模型 JSON（schema 约束的静态建筑/园区数据）；本 skill 输出浏览器里跑的动态 Web 3D 场景与动画。两者互补：要一份能导入的数据用 town-model-gen，要一个会动的场景用本 skill。

## 未核实的事

- 颜色面积占比：原仓库代码没写，本 skill 不编数字。
- 搅拌筒转速：原仓库代码值（5 / 1.6 rad/s）与卡片文案（14 rpm）不一致，以代码为准。
- 声音与碰撞扫查：原仓库有 score.py 配乐与 collide 扫查，本 skill 只保留检查法，配乐做法未完整拆解。
