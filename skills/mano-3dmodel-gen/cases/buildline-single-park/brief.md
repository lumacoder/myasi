# 案例简报：施工工地 · 单园区变体（Buildline-single-park）

- 场景：施工工地（Buildline，Nyxera0x/simulator 1:1 基线上的单园区变体）。
- 主体：一车混凝土从搅拌站到浇筑点；加工、装填、砌筑三段作业全在同一园区内。
- 动作：搅拌站内装填 → 园内主干道东行 → 坡道门倒车 → 摆溜槽浇筑 → 两地块砌墙。
- 情绪：紧凑、有序、玩具感。
- 时长：43.7s；节拍：装填 14–17.4 / 行驶 17.6–22.2 / 倒车 22.4–26 / 摆槽 26.2–27.2 / 浇筑 27.4–33.6 / 砌墙 33.8–40。
- 出口：Web 3D 模型展示页（纯模型，零 DOM 覆盖层）。

## 单园区布局规则（本案例的通用提炼，见 SKILL.md §2）

- 场景只有一个园区；加工、装填、砌筑等作业全在园区内。
- 道路与绿植与园区等长，不外延；园外孤儿构件（失联的车道、门）删除，不留。
- 布局仍以地块矩形为唯一基准框推导：围栏只扩容纳作业所需的一侧，其余三界不动。
- 作业移入园内时，车辆路线随之改走园内路 + 共用大门；路线逐点校验（禁尖点、贴地、避障）不变。
- 相机关键帧随作业新址重算（首帧目标取新园区中心附近，距离按新园区尺寸重算）；fov / 方位 / 俯仰不变。

## 本案例的布局差量（相对基线，数字来源：变体 CHANGELOG §1）

- 搅拌站整体平移至园内新址 (−60,−10)，围栏仅西扩一侧（FX0 −38.5 → −77），园区 x 长 75 m → 113.5 m。
- 两砌筑地块移入园内：P2 (26.5,−23.8)、P3 (27.5,−7)；翻斗车门关闭，坡道门改为 TP-14 与 M-21 共用门。
- 园内新增主干道 42.5×5 m（z −22..−17）；马路截断至与园区等长（113.5 m，x −77..36.5），树行同步截断为 9 棵。
- 挖掘机挖点南移至 (26,2)、停放点 (10,17.5) 朝西；翻斗车离场改走坡道门，终点收至马路东端 (36.5,−40.5)。
- 其余一律不动：43.7s 时间轴、全部点击时刻、灯光/阴影/雾、搅拌车、浇筑动画、基坑、钢筋、楼板、土堆、临建。
